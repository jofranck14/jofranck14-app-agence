# Application Agence de Voyage

## Description
Application web pour gérer une agence de voyage (réservations, clients, trajets, paiements,...).

## Technologies
- React.js
- Node.js (Express)
- Mysql
-Tailwind.css

## Fonctionnalités

- Authentification
- Gestion des réservations
- Dashboard
- Paiement (Stripe)
